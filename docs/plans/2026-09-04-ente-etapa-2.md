> ## ✅ EJECUTADO · 2026-09-04
>
> Las siete tareas hechas y verificadas: 1506 tests del front y 148 del back,
> lint, tipos y build en verde. **Cuatro desviaciones**, y las dos primeras
> habrían dejado la etapa rota:
>
> **1 · `leaveV02()` borra la palabra al salir, y el ente despierta al volver.**
> O sea siempre después. La pregunta que te mide no habría tenido nunca contra
> qué compararse: habría caído siempre en la mentira. El primer arreglo —no
> borrarla al salir— también estaba mal: hay dos tests que atan la invariante de
> que la bandera y la palabra se guardan y se pierden juntas, para que no exista
> «dentro y sin salida». Son deliberados y no se tocan. La solución buena es que
> **la palabra la guarde el registro del viaje** (`markV02RoundTrip`), que ya
> existía: la misma clave que decía que cruzaste, diciendo además por dónde.
>
> **2 · La mentira sólo caduca si queda otra puerta.** Darla por tragada cuando
> es el único camino a `hablando` obligaba a repetirla para no encerrar a nadie,
> y repetir una afirmación dos frases después lo delata como un guion en bucle.
> Sin palabra guardada no caduca: se queda en pie esperando. Que tenga paciencia
> le queda bien.
>
> **3 · La cuarta trampa —la broma de mandarte a buscar algo que no está— se
> movió a la etapa 3.** Necesita el mecanismo de dejarte cosas: sin él, «andá a
> buscar» no tiene dónde mandarte.
>
> **4 · El ente hablaba de usted en ocho frases.** Corregido a voseo, que es
> como habla el resto de la app, con un test que lo vigila. El usted lo pone a
> distancia y él no está lejos: está detrás de la pantalla, mirándote.

**Objetivo:** que el ente deje de contestar y empiece a **medirte** — cuatro

sabe la palabra de la v0.2, qué procesos hay y qué tiene la papelera.

```ts
/** Deja una pregunta en el aire, o la retira. */
export function setAsk(ask: EntityAsk | null) {
    const actual = readEntity();

    if (ask === null) {
        const { asking: _fuera, ...resto } = actual;
        store(resto);
```

```ts
// src/lib/system/entityTrials.ts

/**
 * Las trampas: cuál toca y cómo se verifica.
 *
 * ⚠ NINGUNA INVENTA ALMACENAMIENTO PARA COMPROBARSE. La app ya sabe con qué
 * palabra entraste a la v0.2, qué procesos hay y qué tiene la papelera. Una
 * trampa que necesitara su propio registro sería una trampa que se puede
 * desincronizar, y entonces no mide nada.
 *
 * Módulo puro: sin estado, sin DOM, sin relojes. Recibe dónde está el ente y
 * qué sabe la app, y devuelve qué toca. Se prueba como una tabla.
 */

import type { EntitySnapshot } from '@/lib/system/entity';

export type Trial =
    /** «¿con qué palabra entraste a la 0.2?» — la única que él puede comprobar. */
    | 'word'
    /** Afirma algo falso que un comando desmiente. */
    | 'lie'
    /** «puedo limpiar todo esto» — aceptar cuesta de verdad. */
    | 'offer'
    /** «escribí //reset. vas a descubrir algo.» */
    | 'dare';

/** Lo que la app ya sabe y él consulta. */
export interface TrialWorld {
    /** La palabra con la que se entró a la v0.2, o `null` si nunca se entró. */
    word: string | null;
}

/**
 * A los cuántos intercambios de la fase salta cada cosa.
 *
 * No son cifras de dificultad: son márgenes para que nada suene a formulario.
 * Soltar la pregunta en la primera frase de `burlon` la convertiría en un
 * trámite; dejarla para la décima haría que nadie llegara.
 */
const MIDE_A_LOS = 3;
const OFRECE_A_LOS = 2;
const RETA_A_LOS = 5;

/**
 * Qué trampa toca ahora, o `null` si ninguna.
 *
 * ⚠ SIEMPRE DEVUELVE UNA PUERTA EN `burlon`. Las dos que abren `hablando` son
 * `word` y `lie`, y no pueden cerrarse las dos a la vez: sin palabra guardada
 * cae en `lie`, y con la mentira ya tragada vuelve a `word`. Si las dos se
 * cerraran, el juego se quedaría sin final y sin dar ningún error.
 */
export function trialDue(
    snapshot: EntitySnapshot,
    world: TrialWorld
): Trial | null {
    if (snapshot.phase === 'burlon') {
        if (snapshot.exchanges < MIDE_A_LOS) return null;

        // Sin palabra guardada no hay nada que comprobar, y preguntarla sería
        // un farol. Miente, que también abre.
        if (world.word === null) return 'lie';

        // Y si ya te la tragaste, esa puerta quedó cerrada: vuelve a medirte.
        return snapshot.lieSwallowed ? 'word' : 'word';
    }

    if (snapshot.phase === 'hablando') {
        if (snapshot.dared) return null;
        if (snapshot.exchanges >= RETA_A_LOS) return 'dare';
        if (snapshot.exchanges >= OFRECE_A_LOS) return 'offer';
    }

    return null;
}

/**
 * ¿Acertó la palabra?
 *
 * Se compara sin mayúsculas ni espacios: la palabra se descifra del morse a
 * mano y se teclea como salga. Exigir la forma exacta castigaría el descifrado,
 * que ya costó, en vez de la comprensión.
 */
export function wordIsRight(answer: string, stored: string | null): boolean {
    if (stored === null) return false;

    return answer.trim().toLowerCase() === stored.trim().toLowerCase();
}
```

⚠ El `return snapshot.lieSwallowed ? 'word' : 'word'` de arriba es
deliberadamente redundante para que se lea la intención, pero **el linter lo va
a marcar**. Sustituirlo por `return 'word';` con el comentario encima.
