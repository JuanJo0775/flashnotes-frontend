# El ente · etapa 3 · te deja cosas

> **Para quien lo ejecute:** SUB-SKILL OBLIGATORIA: `superpowers:subagent-driven-development`
> o `superpowers:executing-plans`. Los pasos van con casilla (`- [ ]`).

**Objetivo:** que el ente deje de ser sólo alguien con quien hablás y empiece a
**dejarte cosas** — notas con información falsa, una broma que te manda a buscar
lo que no existe, y la nota que te encontrás cuando volvés al día siguiente.

**Arquitectura:** un módulo puro nuevo, `entityNotes.ts`, decide **qué nota
toca** y **qué dice**; se inyectan en la papelera del lado del cliente, por el
patrón que ya usan el archivo fantasma (`ghostFile.ts`) y el resto de arte
(`artScrap.ts`) — nunca existen en la base de datos. `entity.ts` guarda lo poco
que hace falta: cuáles ya dejó y cuándo estuviste por última vez.

**Stack:** TypeScript, React 19, Next.js 16, Jest + ts-jest.

**Spec:** [`docs/specs/2026-09-03-ente.md`](../specs/2026-09-03-ente.md) · §Lo que te deja cuando no estás
**Etapas anteriores:** [1](2026-09-03-ente-etapa-1.md) · [2](2026-09-04-ente-etapa-2.md)

## Restricciones globales

- **Alcance: las notas y la broma. Las VENTANAS no.** Las de error fantasma
  están cableadas al bloqueo, y esa capa de UI se toca entera en la etapa 4 con
  la pared que se safa. Hacerlas ahora significaría tocarla dos veces.
- **`PIDIENDO` y los favores siguen fuera.** Van con la etapa 4.
- **⚠ LAS NOTAS QUE DEJA NUNCA EXISTEN EN LA BASE DE DATOS.** Se inyectan al
  leer la papelera, como el fantasma y el resto de arte. Una nota del ente que
  llegara al backend sería una nota de verdad, y borrarla fallaría.
- **⚠ LO FALSO TIENE QUE SER COMPROBABLE.** Igual que su mentira hablada: lo que
  dice en las notas tiene que poder desmentirse con algo que ya existe. Falso
  que no se puede descubrir no es una trampa, es una app rota.
- **El ente habla en minúsculas y de vos**, también por escrito. El test del
  voseo se amplía a las notas.
- **Los dos idiomas, y el inglés no es calca.**
- **TDD**, y `npm run check` desde la raíz del workspace.

```ts
/**
 * Cuándo estuviste por última vez.
 *
 * ⚠ VIVE EN SU PROPIA CLAVE y no en el estado del ente, porque no es cosa suya:
 * es cuándo estuviste vos. Meterlo dentro haría que despertarlo o dormirlo se
 * llevara por delante la cuenta de la ausencia.
 */
const SEEN_KEY = 'flashnotes:seen';

/**
 * Cuánto tiene que pasar para que cuente como «te fuiste».
 *
 * ⚠ OCHO HORAS, y tiene que ser largo. Si bastaran veinte minutos la nota
 * saldría por irse a comer, y entonces no dice «volviste»: dice «te
 * distrajiste», que no tiene ninguna gracia. Ocho horas es dormir.
 */
export const AWAY_ENOUGH = 8 * 60 * 60 * 1000;

/** Anota que estás acá. */
export function markSeen(now: number = Date.now()) {
    try {
        localStorage.setItem(SEEN_KEY, String(now));
    } catch {
        // Sin persistencia no hay día siguiente. Aceptable: se pierde una nota,
        // no el juego.
    }
}

/**
 * Cuánto llevabas sin venir, o `0` si es la primera vez.
 *
 * `0` en la primera visita es deliberado: nunca estuviste, así que no volviste.
 * Una nota de bienvenida al primer arranque no sería «volviste», sería un
 * tutorial — y él no da la bienvenida a nadie.
 */
export function awayMs(now: number = Date.now()): number {
    try {
        const crudo = localStorage.getItem(SEEN_KEY);
        if (crudo === null) return 0;

        const antes = Number(crudo);
        if (!Number.isFinite(antes)) return 0;

        return Math.max(0, now - antes);
    } catch {
        return 0;
    }
}
```

`SEEN_KEY` ahí dentro, y comprobarlo con el test que ya existe.

Crear `src/lib/system/entityNotes.ts` con `LeftNote`, `NoteWorld`, `noteDue`,

```ts
export function noteDue(
    snapshot: EntitySnapshot,
    world: NoteWorld
): LeftNote | null {
    // La fachada no escribe notas.
    if (snapshot.phase === 'dormido' || snapshot.phase === 'receloso') {
        return null;
    }

    /*
     * ⚠ LA DEL DÍA SIGUIENTE GANA A TODO.
     *
     * Volvés después de un día y hay algo esperándote: ése es el momento, y
     * dura una vez. Dejar que lo ocupe otra nota desperdicia lo único que él no
     * puede fingir.
     */
    if (world.awayMs >= AWAY_ENOUGH && snapshot.leftVuelta !== true) {
        return 'vuelta';
    }

    if (snapshot.leftFalsa !== true) return 'falsa';
    if (snapshot.leftBroma !== true) return 'broma';

    return null;
}
```

Y los textos, con el mismo criterio de la voz: minúsculas, voseo, sin firmar.
La `falsa` tiene que nombrar `//panic` y decir que repara — es lo que la hace
comprobable.
